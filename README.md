# Veect shadcn kitchen

A Vite + React + TypeScript test repository for [Veect](https://veect.com):
Tailwind CSS v4 and 17 real [shadcn/ui](https://ui.shadcn.com) components
(button, card, badge, input, label, textarea, checkbox, switch, tabs,
alert, avatar, separator, skeleton, select, accordion, progress, tooltip),
composed on one demo page.

```bash
npm install
npm run dev
```
